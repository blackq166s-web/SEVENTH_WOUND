# SEVENTH WOUND · 第七道伤

《血腥大地 / Crimsonland》的复刻原型：俯视角双手射击（twin-stick）割草生存。

纯前端实现 —— HTML5 Canvas + 原生 ES Module，**零依赖、零构建**。所有美术与音效都是运行时程序化生成的，没有一张图片、没有一个音频文件。

> 本目录即**项目实现根**（代码、工具、资产生成逻辑都在这里）。仓库级规则见 `../AGENTS.md`，当前阶段与待办见 `../STAGE.md`。

---

## 运行

双击 `start.bat`（会启动本地静态服务并打开浏览器）。

或者手动（在**本目录**下执行）：

```bash
node tools/serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

> 必须通过 http 访问。直接双击 `index.html`（file://）会因为 ES Module 的跨域限制加载失败。

要求：任意 2021 年后的 Chrome / Edge / Firefox。

## 已实现

**战斗**
- 9 种武器，双名显示（世界名 · 类型）：第一声 · 手枪 / 连祷 · 突击步枪 / 口吃者 · 冲锋枪 / 宽恕 · 霰弹枪 / 焚稿 · 火焰喷射器 / 结晶之喉 · 等离子枪 / 穿层者 · 电磁步枪 / 墓碑 · 火箭筒 / 蜂巢 · 转轮机枪
- 6 种敌人：腐化者、疾行者、织网者、哨眼（远程）、融生体、守层者（Boss）
- 8 种子弹行为：普通、穿透、爆炸溅射、追踪、火焰（点燃 DoT）、等离子、电磁、毒
- 血液/尸块粒子 + 持久血迹图层（自动淡出）、弹壳火花、爆炸烟雾、屏幕震动、命中定格
- 敌人 AI：追击 / 蛇形突进 / 保持距离射击

**成长**
- 20 个可叠加 Perk（伤害、移速、装填、弹匣、追踪弹、点燃、中毒、穿透、暴击、闪避、时缓、备用武器槽……）
- 升级时三选一，可连续升级连续选择
- 经验晶体掉落 + 磁吸拾取

**模式**
- 竞技场（生存）：无尽潮汐，每 24 秒一次潮汐，每 5 次潮汐守层者苏醒，难度随潮汐成长
- 下潜（关卡）：6 层手工关卡（数据驱动），逐层推进：消化场 / 疾走回廊 / 织网窟 / 酸池哨塔 / 融生腔 / 守层者之厅

**表现**
- 全程序化精灵（离屏预渲染缓存，不走每帧重绘）
- WebAudio 实时合成音效，无外部资源
- 缩放镜头、准星方向前探、暗角、低血预警
- 屏幕边缘威胁指示器：视野外敌人按方向贴边提示，最多 8 个、近的优先，Boss 单独样式
- 独白系统：屏幕底部打字机，非阻塞（不暂停 `update`、不挡输入），开局 / 首次升级 / 层主登场 / 首次低血 / 死亡各一句
- 层间文本卡与层主登场：眉批 + 主标题 + 副题的中央横幅，1.6s 镜头轻推（不改缩放，准星不偏）

## 本地约定

- 一切验证走 http，不用 `file://`。
- 调试入口：`window.__game`；URL 参数 `?auto=survival&warm=1500&bot=1`。
- 本机 Chrome 路径：`C:/Program Files/Google/Chrome/Application/chrome.exe`（`tools/*.mjs` 已硬编码）。
- `shots/*.png` 是验证截图产物，不入库。

## 开发

在本目录下执行：

```bash
node tools/smoke.mjs     # 无浏览器跑 1 万多帧，捕获运行时异常 + 输出平衡数据
node tools/shoot.mjs     # 真浏览器截图到 shots/（需先启动 serve.mjs，默认 8124 端口）
node tools/fps.mjs       # 端到端帧率（需服务在 8124）
```

从仓库根目录执行也可以（脚本内部按自身位置定位资源）：

```bash
node 03_项目实现/tools/smoke.mjs
```

调试入口：页面里 `window.__game` 就是 Game 实例。
URL 参数 `?auto=survival&warm=1500&bot=1` 会自动开局、快进 1500 帧、并让简易机器人自己瞄准射击 —— 用来快速到达"混战中"的状态。

## 下一步（建议优先级）

1. **手感**：冲刺/翻滚、手柄支持、受击顿帧曲线
2. **内容**：更多武器（散弹榴弹、激光、连锁闪电）、更多敌人（自爆虫、召唤者、飞行单位）
3. **模式**：通关武器限制、无尽 Rush、每日挑战、排行榜
4. **表现**：粒子改为对象池、Boss 登场演出
5. **壳**：Electron 打包成 exe（`index.html` 不用改）

> 以上为产品向建议；实际排期以 `../STAGE.md` 为准。
