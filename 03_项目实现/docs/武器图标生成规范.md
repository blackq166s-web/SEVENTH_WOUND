# SEVENTH WOUND — 武器图标生成规范

> 本文件发给绘图 Agent。完成后的图片**按第 3 节命名**保存，交给主控 Agent 接入游戏。

## 你的任务（直接照做）

生成 **17 张武器图标 PNG**，一张一张来，不要等确认。

1. 按第 2 节的顺序逐个生成。
2. 每张的提示词 = **通用风格** + **该武器的特征一句**，两段连起来用。
3. 严格按第 3 节的**文件名**保存到 `D:\my_game_2\03_项目实现\assets\weapon-icons\`。
4. 遵守第 4 节的硬约束。
5. 全部生成完后回报"17 张已生成完毕 + 保存路径"。

---

## 1. 通用风格（每条提示词都带这段）

```
Minimal weapon icon, FLAT SOLID SILHOUETTE, side view, muzzle pointing RIGHT.
Single dark color fill, no gradients, no shading, no texture, no realism.
Just a clean readable outline/silhouette, like a minimalist app icon.
Transparent background, single icon, centered, 128x128 px PNG.
```

核心：**极简轮廓、单一颜色、不写实**。一把枪就是一个干净可辨认的剪影，
缩到 40px 也一眼认得出是什么枪。

## 4. 出图硬约束（违反即返工）

1. **极简轮廓**：单一颜色剪影即可，不要渐变、不要高光、不要写实纹理。用户原话"用一个轮廓代替都行"。
2. **侧视、枪口朝右**。
3. **透明背景**，图标之外完全透明。
4. **128×128 px PNG**，图标占画布 70–85%。
5. **单张**，每个武器一张，不要精灵表。
6. **可辨认性优先**：缩到 40px 也认得出是哪把枪（轮廓特征要足够明显）。

## 5. 交接方式

1. 17 张 PNG 按第 3 节命名，放进 `assets/weapon-icons/`。
2. 把该目录的 17 张图一起交给主控 Agent（发文件或告诉路径）。
3. 主控 Agent 负责：读图 → 替换现有程序化图标 → base64 内联进单文件 → 接入 HUD/武器选择面板/图鉴。
