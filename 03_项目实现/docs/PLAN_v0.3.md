## 0. 先说清楚"粗糙"是糙在哪

体检了 `src/render/sprites.js`（438 行）和地面生成，问题不在"画得不够细"，在**缺三样东西**：

| 缺什么 | 现状证据 | 后果 |
| --- | --- | --- |
| **统一的色彩脚本** | 6 种敌人各用一套随手取的色：僵尸 `#8fae5e` 绿、疾行者 `#c98a6a` 橙、蜘蛛 `#4a4a5e` 蓝灰 | 跟 `STORY §10` 的六层配色分区（锈红/暗红/腐绿/黄绿/紫/深红）**完全对不上** |
| **剪影语言** | 6 个敌人全是 `radial-gradient 圆形 + blobPath 抖动 + 一对眼睛` | 去掉颜色几乎分不出谁是谁；玩家也一样，靠蓝色光晕才认得出 |
| **分层身份** | 全 6 层共用**同一张** 256px 地面瓦片，基色 `#1e222a` 冷灰蓝 | 走到第六层和第一层长得一样，"下潜"没有视觉回报 |

`STORY §10` 其实已经写好了答案（配色分区表 + "地渊造物不对称 / 人类遗留物对称"的形状语言），只是代码没实现。**v0.3 的美术任务就是把这套设定真的做出来**，不是"再画细一点"。

## 1. 美术升级（三批，按视觉回报排序）

### V1 · 分层视觉系统（改动小、回报最大）

新增 `src/render/palettes.js`：六层各一套，全部数据化。

```js
export const PALETTES = {
  '第一章 · 消化场': { ground:'#241a16', moss:'#3f6b2a', blood:'#8f2a1c',
                     fog:'rgba(60,20,16,0.30)', mote:'rgba(220,180,120,0.5)', rim:'#c9d6e5' },
  ...
};
```

落地项：

- **地面按层生成**（`makeGroundTile(pal)` 缓存 6 张）：消化场=肉膜+骨屑，回廊=蠕动纹理，织网窟=蛛丝反光，哨塔=酸液焦痕，融生腔=紫色结晶，守层者之厅=深红砖缝
- **血迹/弹坑/尸体颜色**跟着该层的 `blood` 走（现在全用敌人自身 `blood` 字段，勉强但对不齐）
- **暗角与雾色**按层（现在统一 `rgba(0,0,0,0.34)`）
- **环境浮尘**按层配色（骨屑 / 孢子 / 酸雾 / 结晶微光）
- **武器箱、治疗包**统一"人类遗留物"色板（骨白 + 工业黄），跟地渊造物明确区分

验收：6 层并排截图能一眼区分；同一敌人在不同层有对应色调偏移。

### V2 · 精灵重绘（这批最费工，也最出效果）

原则（写进代码注释，新人看得懂为什么这么做）：

- **地渊造物一律不对称**：重心偏、肢体数量不等、轮廓有破口
- **人类遗留物一律对称**：硬边、直角、工业分模线
- **三色调**（暗部 / 中间调 / 亮部）+ **固定方向轮廓光**（左上），不再用径向渐变当体积
- **动画从 2 帧提到 4 帧**（呼吸 / 步态 / 蓄力），现在只是"形状抖一下"

具体：

| 对象 | 现在 | v0.3 |
| --- | --- | --- |
| 玩家 | 56px，无剪影设计 | 72px：战术外套 + 左臂布条（层数可见）+ 无头盔头部 + 枪与手分离；跑动有 4 帧 |
| 腐化者 | 绿球 + 眼睛 | 拖着断腿的前倾剪影，胸腔开口，菌丝从缺口长出来 |
| 疾行者 | 橙球 + 爪子 | 四肢着地的长条剪影，脊椎外露，速度快时拉出残影 |
| 织网者 | 蜘蛛腿 + 圆身 | 明显不对称：一侧腿更多、腹部有卵囊膨起 |
| 哨眼 | 蜥蜴椭圆 | 独眼占头部一半，背部有"射口"结构，蓄力时眼部发光 |
| 融生体 | 紫球 | 多个体块粘在一起、能看出"人手/兽爪"的碎片轮廓 |
| 守层者 | 88px 大方块 | 人形但比例错乱：一只手是炮管，胸腔有七道旧枪伤（`STORY §2.2` 的自伤梗） |
| 补给物 | 十字/箱子占位 | 医疗包=金属盒+绿色药剂管；武器箱=军械箱+枪管露出 |

验收：**灰度辨认测试** —— 把截图转灰度、去掉颜色，仍能靠剪影区分 6 种敌人。

### V3 · 氛围与反馈（最后做，锦上添花）

- 环境：漂浮孢子/尘埃按层、地面上缓慢明暗"呼吸"、边缘呼吸光
- 受击：材质反应（肉块撕裂 vs 甲壳剥落）+ 溅射按层色
- 死亡：残响外溢（上升的细丝状粒子）代替单纯血块，呼应"残响被记录"
- 武器开火：弹壳、烟、地面焦痕按武器类型变化

验收：录一段 20 秒视频看观感（截图不足以判断氛围）。

## 3. 升级选项：20 → 32，从"加数值"变成"改玩法"

现在 20 个刻印里 15 个是纯数值（伤害 +22%、装弹 +35%），选起来没有决策感。分三步改：

### 3.1 新增 12 个机制型刻印（按实现复杂度分档）

**低复杂度（复用现有子弹/敌人系统）**

| 刻印 | 效果 | 实现要点 |
| --- | --- | --- |
| 弹跳弹 | 子弹命中后按角度反弹 1 次 | `bounce` 字段 + 命中时反射速度 |
| 连锁 | 命中时对最近敌人跳一次伤害 | 复用爆炸逻辑改单体 |
| 尸爆 | 击杀时尸体炸开（已有 `explodeOnKill`，改成可见的"尸体"） | 已有 |
| 地雷 | 每 3 秒在脚下留一颗，敌人踩到炸 | 新拾取物类型 |
| 冰痕 | 移动路径留减速粘液 | 复用 `enemySlow`，按位置判定 |

**中复杂度（需要新实体/状态）**

| 刻印 | 效果 |
| --- | --- |
| 无人机 | 环绕的自动射击小机（永久存在，死了 5 秒后重生） |
| 时停泡 | 命中 6 次后触发 1.2 秒局部减速领域 |
| 双持 | 副武器同时开火（弹匣各自消耗） |
| 血偿 | 受伤时把伤害转成下一发子弹加成 |
| 玻璃大炮 | 最大生命 -30%，伤害 +45%（明确的负面） |

**高复杂度（留到 v0.4，先不做）**：召唤物 AI 编队、地形改造、刻印合成树。

### 3.2 稀有度与"禁忌"标签

- **普通**（数值型）：现在的 20 个
- **稀有**（机制型）：带边框 + 轻微光晕，出现率 ~25%
- **禁忌**（侵蚀线专属）：收益极大 + 侵蚀值翻倍（+16 而不是 +8），卡面标红并写明代价

选禁忌不再是"顺手拿个强的"，而是"我要不要现在就开始变怪物"——这才是侵蚀值该有的决策点。

### 3.3 选择结构

- **每局一次重掷**（`R` 键）：三张都不想要时换三张
- **协同标记**：新刻印与已持有刻印有组合时，卡面显示 `＋协同`（例如 火焰喷射器 + 纵火狂 + 尸爆）
- **不再给满血时出现"治疗"类刻印**（现在会出现没用的选项，纯属浪费一个格子）

验收：smoke 断言（32 个刻印 ID 唯一、`line` 合法、稀有度字段齐全、重掷只能用一次）；升级卡截图含稀有度与协同标记。

## 5. 风险与止损

1. **美术越改越丑**：每批只改一处（先 `palettes`，再剪影，再光影），每步截图与上一版并排；不好看就回滚那一批，不留"半成品新风格"。
2. **平衡被打乱**：+6 武器 +12 刻印都会改难度曲线。用 `?seed=` + `determinism.mjs` 固定条件对比，改前先跑一版基线数据。
3. **刻印实现拖时间**：机制型刻印按复杂度分档，高复杂度的（召唤物 AI、合成树）直接推到 v0.4，不在这一轮做成半吊子。
4. **工作量**：A+B 是主要工时，C/D 相对快。E 可随时砍掉，不影响"不再粗糙"。

### S6-A · 层色系统（2026-10-21 完成）

**做了什么**

| 文件 | 内容 |
| --- | --- |
| `src/render/palettes.js`（新，190 行） | 6 层 + 竞技场共 7 套配色：`style`（flesh/web/acid/crystal/plate）、地面基色/斑驳/颗粒/裂纹、`blood`、`glow`、`fog`、`ambient`；`paletteForLayer()` / `mixHex()` |

| `src/core/fx.js`（新，26 行） | 表现层随机 `fxRandom()`（xorshift32），与玩法种子流彻底分开 |
| `src/game/game.js` | `setPalette()` / `start()` 与 `loadQuest()` 切层色 / 暗角用该层雾色 / 血迹混该层底色 / 画布叠宏观层 |

**关键决定：渲染路径不许抽种子流**

`render()` 里原本有 `M.random()`（火焰子弹的半径与颜色抖动）。它属于"每帧渲染"，一旦抽种子流，同 seed 的结果就会随"这一帧渲染没渲染"变化——`determinism.mjs` 只跑 `update`，所以之前没暴露，但真人跑起来数据就飘了。现在渲染与美术生成统一走 `fxRandom()`。

证据：S6-A 改完后 `determinism.mjs` 的指纹仍是 `7e83aacaca6e49fe`，与改动前**完全一致** —— 说明只动了表现层，玩法数值一位没变。

**踩坑：平铺感**

- 256px 瓦片 + 5 摊酸池 → 屏幕上能数出"同一摊每 256px 重复一次"，一眼假。
- 改成 512px + 宏观叠层（同一套材质函数**再随机生成一次**、放大 2.7 倍半透明叠加）后，两层图案互不对齐，周期被打散，肉眼基本看不出网格。
- 织网层的教训：3 张**大**网 = 立刻暴露网格；9 张**小**网 + 更细的线 = 变成纹理。
- 第六层砖面原本是严格棋盘格（隔块加亮），远看像国际象棋盘；改成每块随机明暗（alpha 0.08–0.38）才像"旧地板"。
