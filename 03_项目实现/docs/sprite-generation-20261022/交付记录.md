## 文件检查

- 七张均为 256×256、32 位 RGBA PNG。
- 四角及完整画布边界 alpha 全为 0。
- 完整非透明轮廓最长边均为 184px，占画布 71.875%；未拉伸变形。
- 原图有 alpha 1–3 的极淡杂点；取 alpha≥4 的主体边界并外扩 2px 取景后等比缩放，保留裁切区域内原始透明通道。生成原图仍保存在 Codex 的原始输出目录。
- 文件指纹、边界与尺寸见 [verification.json](verification.json)。

可在仓库根执行以下命令重新检查文件，不需要图片生成服务或额外依赖：

```powershell
& './03_项目实现/tools/prepare-sprites.ps1' -VerifyOnly
```

通过标志：`SPRITE_ASSETS_OK`。脚本使用 Windows 自带绘图库，在 PowerShell 7 下自动调用 Windows PowerShell；默认生成模式拒绝覆盖已有图片，`-ReplacePrepared` 仅供有意重新整理本次生成素材。
