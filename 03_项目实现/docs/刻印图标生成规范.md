## 你的任务（直接照做）

生成 **25 张刻印图标 PNG**，一张一张来，不要等确认。

1. 按第 2 节的顺序逐个生成。
2. 每张的提示词 = **通用风格** + **该刻印的语义符号一句**，两段连起来用。
3. 严格按第 3 节的**文件名**保存到 `D:\my_game_2\03_项目实现\assets\perk-icons\`。
4. 遵守第 4 节的硬约束。
5. 全部生成完后回报"25 张已生成完毕 + 保存路径"。

---

## 1. 通用风格（每条提示词都带这段）

```
Minimal game icon, a single CLEAN GEOMETRIC SYMBOL centered on canvas.
Flat vector style, no gradients, no shading, no texture, no realism, no text.
Thin-to-medium line weight, one accent color fill/stroke.
Transparent background, 128x128 px PNG, symbol occupies 60-75% of canvas.
Roguelike ability icon, like Hades boon icons.
```

核心：**一个干净的几何符号**，扁平矢量，单一强调色，不写实、不放大字。
图标要能缩到 40px 仍可辨认语义。

## 4. 出图硬约束（违反即返工）

1. **单一几何符号**，扁平矢量，不写实、不放大字、不出现任何文字。
2. **单一强调色**：每种图标可用一种主色，但不要多彩渐变。
3. **透明背景**，图标之外完全透明。
4. **128×128 px PNG**，符号占画布 60–75%，四周留白。
5. **单张**，每个刻印一张，不要精灵表。
6. **可辨认性优先**：缩到 40px 仍能认出语义（符号要简洁、形状特征明显）。

## 5. 交接方式

1. 25 张 PNG 按第 3 节命名，放进 `assets/perk-icons/`。
2. 把该目录的 25 张图一起交给主控 Agent（发文件或告诉路径）。
3. 主控 Agent 负责：读图 → 替换现有程序化几何图标 → base64 内联进单文件 → 接入刻印选择面板 / 图鉴。
