# 可玩版 v0.3.0 · 归档说明

**这一版是按你上一轮试玩的意见改的。**

---

## 怎么玩

双击 `SEVENTH-WOUND-0.3.0.html`。不装东西、不联网、不开服务。

单文件 196 KB，整个游戏（美术与音效）都是代码运行时生成的。建议 Chrome / Edge，窗口 1280×720 以上。
给别人玩就发这两个文件：`SEVENTH-WOUND-0.3.0.html` + `运行说明.txt`。

## 针对你的三条意见，改了什么

| 你的意见 | 这一版 |
| --- | --- |
| **美术粗糙、不符世界观** | 实现 `STORY §10` 的配色分区：六层各有材质（肉膜 / 蛛网 / 酸池 / 结晶 / 砖缝）与雾色；怪物全部重画，统一光源、4 帧动画；玩家与怪物的剪影重新设计（人形读法：头在前、肩在两翼、腿在后）；地面提亮、暗角减淡、血迹压暗，混战里看得清 |
| **武器少、前中期捡不到** | 9 → 15 把，每把职能不同（点射 / 三连发 / 贴脸链锯 / 腐蚀 / 冰冻控场 / 蓄力穿透）；掉落改 5% + **开局 22 秒必掉一把** + **连续 90 秒没掉则下一只怪必掉**，箱子按等级发光柱 |
| **升级选项无聊** | 20 → 25 张：新增 5 个机制型（跳弹 / 连锁 / 布雷 / 冰痕 / 双持）；分普通 / 稀有 / **禁忌**（侵蚀值翻倍，卡面标红）；每局一次重掷；卡面显示「＋协同」；满血时不再推治疗类 |
