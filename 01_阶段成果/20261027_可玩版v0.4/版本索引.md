## 1. 这一份是什么

**v0.3.0 之后连续 11 个阶段（S6 收尾 + S7~S16）的完整快照。** 这段时间的主题从「美术精进」一路推到「玩法手感」和「内容批次」，期间引入了**图像 Agent 产出 PNG 素材 + 主控接入**的分工管线。

**A. 可玩产物**：`SEVENTH-WOUND-0.4.8.html` —— 单文件，双击即玩。21 个模块内联 + 7 张角色 PNG + 17 张武器图标 PNG（base64），589.6 KB。

**B. 文档**：`docs/PLAN_S7.md`（S7~S16 十批的完整记录与踩坑）、`docs/STORY.md`、`docs/DESIGN_MAP.md`、`docs/角色精灵生成规范.md`、`docs/武器图标生成规范.md`（两份给绘图 Agent 的规范）。

**C. 关键决策（这段时间定下的）**：
- 角色精灵 / 武器图标**不再程序化绘制**，改由图像 Agent 按规范产出 PNG，主控 base64 内联接入（打破了「零资源」铁律，用户授权，AGENTS.md 已更新）。
- 武器**手动替换**（取消自动拾取替换），弹道特殊化（电弧 / 持续激光 / 贯穿散弹）。
- **下潜模式停用**，只保留竞技场（用户临时决策，可回退）。
