# 可玩版 v0.4.8 归档

> SEVENTH WOUND《第七道伤》· 归档时间 2026-10-27

## 这是什么

v0.3.0 之后 11 个阶段（S7~S16）的完整快照：从「美术精进」到「图像 Agent 产图接入」到「玩法手感」到「内容批次」。

## 直接玩

双击 `SEVENTH-WOUND-0.4.8.html` 即可。单文件，无需安装、无需联网、无需开服务。

## 这一版有什么

- **7 张图像 Agent 产出的角色 PNG**（主角 + 6 怪）+ **17 张武器图标 PNG**，全部内联进单文件
- **17 把武器**，各有独特弹道：电弧连锁、持续激光、贯穿散弹、脉冲溅射、蓄力轨道炮……
- **手动替换武器**（捡枪弹对比面板，1 装备 / 2 副武器 / 3 放弃）
- **冲刺**（Shift，短暂无敌）+ 受击方向提示 + Boss 顿帧
- **守层者二阶段**：血量过半转形态，加速 + 环形弹幕 + 召唤小怪
- **图鉴**：地渊造物 / 武器 / 刻印三标签
- **侵蚀台词**：侵蚀值 70/80/92 三档，越深越不像人
- 下潜模式已停用，只保留竞技场
