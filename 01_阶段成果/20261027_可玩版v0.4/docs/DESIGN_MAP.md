# 设定落地映射 · 设定 ↔ 代码

> 配套 `STORY.md`。本文只回答一件事：**设定怎么落到现有实现上，代价多大，怎么验证。**
> 最后更新：2026-10-21

---

## 1. 原则

1. **设定去贴机制，不是机制去贴设定**。潮汐 24 秒、层主每 5 波，这两条设定数字是照抄现有代码的（`game.js` 的 `waveTimer >= 24`、`wave % 5 === 0`），不是反过来。
2. **改动分三级**，A 级（纯文案）可随时做，B 级（小逻辑）按阶段排，C 级（新系统）必须先出设计文档。
3. **一律不改 id**。只改 `name` / `desc` / `brief` 等展示字段，逻辑层不碰，避免破坏掉落、存档、测试断言。

| 路线 | 刻印 id | 名称 |

| 侵蚀（6） | pyromaniac / toxic / death_clock† / time_warp / uber† / **chain** | 纵火狂 / 剧毒之触 / 死亡时钟† / 时间扭曲 / 超级战士† / 连锁 |

† = 禁忌（侵蚀值 +16，卡面标红）。稀有 = 五个机制型，其余为普通。

| 稀有度 | 数量 | 权重 | 含义 |
| --- | --- | --- | --- |
| 普通 common | 18 | 1.0 | 加数值 |
| 稀有 rare | 5 | 0.55 | 改玩法（跳弹 / 连锁 / 布雷 / 冰痕 / 双持） |
| 禁忌 forbidden | 2 | 0.6 | 侵蚀翻倍的大收益 |

**约束**：以后新增 Perk 必须归入三条线之一，并说明"代价"（钢铁=依赖装备、本能=身体改造、侵蚀=侵蚀值）。没有代价的 Perk 不许进侵蚀线。

**侵蚀值落地（P4，已实现）**

| 项 | 值 | 位置 |
| --- | --- | --- |
| 每条"侵蚀"线刻印 | +8（`EROSION_PER_STACK`） | `perks.js` `applyPerk()` |
| 上限 | 100（`EROSION_MAX`） | 同上 |
| ≥40 | 画面红移（径向渐变，随心跳搏动）+ 心跳音 1.15s→0.55s | `game.js` `drawVignette()` / `updateWorld()` |
| ≥70 | 所有敌人移速 ×1.1 + 独白「这双手……不是我的。」 | `enemies.js` / `voice.js` `erosionHigh` |
| 显示 | HP 条下方 5px 侵蚀条（0 时隐藏）+ `侵蚀 N` | `hud.js` |
| 结算 | 死亡面板「最高侵蚀」 | `ui.js` / `game.summary()` |

按 14 层可叠（纵火狂/剧毒/死亡时钟/时间扭曲各 3、超级战士 2）推算，全走侵蚀线会溢出到 100 的上限。

## 6.5 叙事事件 ↔ 代码（P3 落地）

| 叙事事件 | 触发点 | 代码 | 规则 |
| --- | --- | --- | --- |
| 开局独白 | `start()` | `voice.js` 的 `MONO.start`（2 句） | 先进先出，一句打完停 2.5s 再淡出 |
| 首次升级 | `openLevelUp()` | `MONO.firstLevelUp` | 同名每局只播一次（`Voice.seen`） |
| 层主登场 | `spawn()` 判 `def.isBoss` | `bossIntro()` + `MONO.firstBoss` | 1.6s 内镜头向它偏 32% 权重，**不改 zoom** |
| 首次低血 | `updateWorld()` 判 `hp / maxHp < 0.3` | `MONO.firstLowHp` | 同上 |
| 死亡 | `onPlayerDeath()` → `ui.showDead()` | `MONO.death` → `#deadVoice` | 走 DOM：死亡面板会盖住画布 |
| 层间文本卡 | `loadQuest()` | `banner { kicker, text, sub, t, total }` | 2.0s = 0.28 淡入 + 1.2 停留 + 0.5 淡出 |

**加一句独白**：往 `MONO` 里加 key（每行 ≤ 24 字，`smoke.mjs` 会校验），在触发点调 `this.voice.say('key')` 即可。不要自己写计时器或状态——`Voice` 负责排队与生命周期，`drawVoice` 只负责画字。

## 7. 改动分级与验证

| 级 | 内容 | 风险 | 验证 |
| --- | --- | --- | --- |
| **A** | 关卡名、武器名、敌人名、HUD 标签、播报、死亡文案 | 低（纯字符串） | `smoke.mjs` PASS + `shoot.mjs` 出图核对 HUD 不溢出 |
| **B** | Perk 加 `line` 字段并在升级卡显示路线；主角布条随层数变化；死亡界面改字段含义 | 中（动数据结构/绘制） | A 级 + 新断言（`line` 必填、布条数 = 层数） |
| **C** | 侵蚀值机制、守层者登场演出与二阶段、独白/叙事事件、层间过场 | 高（新系统） | 先写设计文档，再单独开阶段，不混进 S1 |

> C 级进度：**独白 / 层间卡 / 守层者登场**已在 P3 落地（见 §6.5）；守层者二阶段与侵蚀值未做。

## 8. 本轮建议执行顺序

1. **先做 A 级全文案**（半小时级）：把设定"贴上去"，游戏立刻有世界观，且零逻辑风险。
2. 出图核对：`shoot.mjs` 看 HUD 是否有文字溢出、Boss 播报是否被遮挡。
3. 再决定 B 级做哪一项——我建议先做「升级卡显示三条路线」，因为它直接让玩家感知到"残响"这个金手指存在。
4. C 级（侵蚀值）留给下一个阶段，它值得单独一轮设计 + 平衡验证。
