## 4. 适用条件

这套设定与文案适用于：

1. 游戏名仍为 `CRIMSON ARENA`（若改用 `SEVENTH WOUND`，见 `docs/NAMING.md` 的 8 处落地清单，其中存档键迁移有丢档风险）；
2. 模式结构为「竞技场（生存，无限潮汐）+ 下潜（六层关卡）」，且潮汐 = 24 秒、层主 = 每 5 次潮汐；
3. 敌人 / 武器 / Perk 的 id 体系未变（`zombie` / `pistol` / `bloody_mess` …），只改了展示名；
4. 仍为纯前端、零依赖、程序化美术。

**一旦出现以下情况，本归档即需出新版本（不覆盖本目录，新建 `20261021_世界观v1_v2`）：**
- 六层结构、敌人体系、武器分类、Perk 三路线中任一条被改动
- 改名落地（`CRIMSON ARENA` → 其他）
- P2/P3/P4 完成，设定与实现的关系发生变化
