# 可玩版 v0.2.0 · 归档说明

**这一份是"第一次能给别人玩"的版本。**

---

## 怎么玩

双击 `SEVENTH-WOUND-0.2.0.html`。就这样——不装东西、不联网、不开服务。

单文件 125 KB，整个游戏（含所有美术与音效）都是代码在运行时现场生成的，没有一张图片、没有一个音频文件。建议 Chrome / Edge，窗口 1280×720 以上。

给别人的话，把这两个文件发过去就够：`SEVENTH-WOUND-0.2.0.html` + `运行说明.txt`。

## 这一版有什么

从 v0.1.0 的"能跑的原型"到 v0.2.0，中间落了四批设定 + 一次发布：

| 批次 | 内容 |
| --- | --- |
| P1 文案 | 六层世界名（消化场 / 疾走回廊 / 织网窟 / 酸池哨塔 / 融生腔 / 守层者之厅）、九把武器双名、敌人世界名、HUD 改「潮汐 / 层」 |
| P2 数据 | 20 个刻印分三条路线（钢铁 8 / 本能 7 / 侵蚀 5），升级卡标路线；主角左臂布条随下潜层数增加 |
| P3 叙事 | 独白队列（底部打字机，不暂停游戏）、层间文本卡、守层者登场（名字条 + 镜头轻推 + 失真音效） |
| P4 机制 | 种子 RNG（`?seed=` 复现）+ 侵蚀值：侵蚀线刻印每层 +8，≥40 画面红移心跳加快，≥70 敌人更快、台词变得"不像人" |
| 发布 | `tools/pack.mjs` 把 18 个模块内联成单文件，版本 0.2.0 |
